**Sammanfattning**  
Den här rapporten handlar om gruppens test av Acme Corp Internportal. Sex personer arbetade med projektet. Gruppen hittade sex säkerhetsproblem: tre kritiska och tre allvarliga.

Resultaten visar problem med inloggning, behörigheter och åtkomst till intern data. Rapporten beskriver vad gruppen såg i testmiljön. Den säger också vad testet inte kunde bekräfta.

Rapporten visar inte att problemen har lagats eller testats igen. Därför bör organisationen planera åtgärder och göra ett nytt test.

**Resultat och uppföljning**  
Projektet dokumenterade sex problem och beskrev deras möjliga följder. Rapporten visar att flera problem kunde påverka varandra. Den säger också att gruppen inte kunde bekräfta kontroll över den underliggande molnmaskinen.

För att följa upp arbetet föreslår jag tre mätetal:

* hur många problem som har lagats och testats;  
* hur lång tid det tar att laga problemen;  
* hur många tester som blir godkända efter lagningen.

Dessa mätetal hjälper organisationen att se om arbetet går framåt. De hjälper också ledningen att förstå om de allvarligaste problemen är lösta.

**Slutsatser**  
Flera säkerhetsproblem kan påverka varandra och göra risken större. Därför behöver organisationen titta på hela systemet, inte bara på varje problem separat.

Jag rekommenderar att organisationen utser en ansvarig person för varje problem, börjar med de kritiska problemen och gör ett nytt test efter lagningen. Resultaten från det nya testet ska skrivas ner.

Rapporten beskriver också olika resultat från två testtillfällen. Organisationen bör undersöka varför resultaten skiljer sig, så att framtida tester kan jämföras på ett tydligt sätt.

**Vad jag tar med mig**  
Projektet visade att säkerhetsarbetet inte slutar när man hittar ett problem. Man behöver också bestämma vem som ska laga det, följa upp arbetet och kontrollera att lösningen fungerar.

Jag har också lärt mig att dokumentation är viktig. Det är viktigt att skriva vad testet visade och vad testet inte kunde bekräfta. På så sätt blir rapporten tydligare och lättare för andra att använda.
